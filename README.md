# Liquid-Cooled Battery Thermal Management Using Neural Surrogates and Reinforcement Learning

## Overview

This repository provides the original CFD training dataset and detailed parameter specifications for neural surrogate modeling and proximal policy optimization (PPO), supporting independent implementation and reproducibility.

## Repository Contents

**1. CFD_Battery_Module_Dataset_263968_History6min_Lookback4min.zip**

Contains 263,968 CFD-derived training samples, incorporating a 6 min temperature-history window and a 4 min input-change lookback window.

**2. Surrogate_and_PPO_Training_Parameters.xlsx**

Provides the neural surrogate architecture, data partitioning, and training hyperparameters, along with the PPO network configuration, optimization parameters, and curriculum-learning settings.

## Reproducibility

The publicly available training dataset and parameter specifications, together with the detailed descriptions of the physical model, reward formulation, and training procedures in the accompanying manuscript, enable independent implementation of the proposed methods and reproduction of the reported results.
